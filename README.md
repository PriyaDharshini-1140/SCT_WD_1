# SCT_WD_1 - Responsive Landing Page

## 📌 Project Overview

This project was developed as part of the **SkillCraft Technology Web Development Internship**.

The objective of this task was to create a **responsive landing page** featuring an **interactive navigation menu** that changes its appearance when the user scrolls the page or hovers over menu items. The navigation bar remains fixed and accessible across all sections of the website.

---

## 🚀 Features

* Fixed Navigation Bar
* Dynamic Navbar Style Change on Scroll
* Interactive Hover Effects on Navigation Links
* Fully Responsive Design
* Modern Hero Section
* Feature & Services Sections
* Smooth Scroll Animations
* Professional UI/UX Design
* Mobile-Friendly Layout

## 💡 How It Works

1. The navigation bar remains fixed at the top of the page.
2. When the user scrolls down, the navbar changes its background and appearance.
3. Navigation links display interactive hover effects.
4. Smooth transitions enhance the user experience.
5. The layout automatically adapts to different screen sizes for responsive viewing.
